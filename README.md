# The Reading Room

A walkable 3D library of 256 public-domain books, centred on the slave narratives and the Black canon: https://library.jordanstrudwick.com/

This repository is the published website only, built from the arcade's `library/` with `deploy/site/build.js`. Where every text comes from, and every change made to it, is in [SOURCES.md](SOURCES.md).

The shared library on this site runs over open public Nostr relays (wss://relay.damus.io, wss://nos.lol, wss://relay.primal.net): the room's layout and the margin notes readers share are public.
